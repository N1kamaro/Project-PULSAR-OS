### FUTURE UPDATES


Honestly, I've been thinking: Yes, the Web OS looks good, but that's not the foundation of the entire project. So I added utilities, such as a browser, a terminal,
and tools for people who want to use microcontrollers with their own systems.

But seriously ... I don't think that's enough.

I'm gonna build a whole Web OS that teaches you how to create your OWN telemetry system, so you can use it for communication, controlling RC devices,
and much more — ALL BY YOURSELF! FULLY OPEN SOURCE!

PULSAR will also have its own firmware flashing system, allowing you to flash code directly from the Web OS itself!!!!

I'm gonna keep building, and this project is gonna be incredible.

Unifying projects.
