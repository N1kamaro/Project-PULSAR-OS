# PULSAR OS

> **A STAR. A SIGNAL. AN INTERFACE.**

PULSAR is a **Web OS** built with HTML, CSS and JavaScript.

It has its own desktop, window manager, apps, terminal, web interface and hardware tools — including direct communication with microcontrollers using Web Serial.

This project started as an simple project and somehow became an entire operating environment :D

## What's inside?

- Desktop & Window Manager
- PULSAR Terminal
- PULSAR Web
- Notes
- Calculator
- Serial Monitor
- Device Manager
- Customization
- Built-in Guide
- Local Storage
- ESP32 communication
