PULSAR is basically a web OS that I've been working on for almost a week! It's a pretty simple project, with a slightly more modern look and, probably my favorite part, a communication system for external microcontrollers that actually works!!

The project comes with a bunch of apps: Signal Log, Notes, Calculator, Terminal, Web (Lowk Browser), Serial Monitor, Device Manager, and finally, the Guide!

There's also a customization menu with 4 wallpapers using real photos taken by the Hubble Space Telescope!

And if you're curious about where they came from, just click on "WALLPAPER SOURCES". All 4 wallpapers are cataloged there, with links to their official pages. You can open them in your normal browser, or even open them using PULSAR's own built-in browser!

The entire web OS also has local storage, which basically means PULSAR remembers your stuff!

For example, if you write something in the Notes app and then reload the entire page, it'll still be there!! :D

Now, a little warning about the WEB browser...

It is NOT compatible with websites that block embedded viewing. So before trying to open something, make sure the website actually allows it to be embedded.

Otherwise, you'll be greeted by the absolutely beautiful:

**"FAILED TO LOAD"**
