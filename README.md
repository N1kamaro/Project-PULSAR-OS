### About it:

PULSAR is basically a web OS that I've been working on for over a Month!! It's a pretty simple project, with a slightly more modern look and, probably my favorite part, a communication system for external microcontrollers that actually works!!

The entire web OS also has local storage, which basically means PULSAR remembers your stuff!
For example, if you write something in the Notes app and then reload the entire page, it'll still be there!! :D

The project comes with sum apps: Notes, Calculator, Terminal, Web (Lowk Browser), Serial Monitor, Device Manager, Custom, and finally, the Guide!



## Customization stuff!!

There's a customization app with 4 wallpapers, if you’re curious about where these images came from, you’ll see the name of the photo in the bottom-right corner of the screen; if you click on it, it will open the official source page directly into system’s web browser! # Final considerations:

I still have a lot to do on this project.
I realized this quite early on; I had hoped to finish it in a single day, but I was hit with the reality that, while the project might appear simple, it is actually anything but. A great deal of the work proved to be very challenging.
I’ll admit that I did use AI at the beginning—not with any malicious intent, but simply to help correct and structure some errors in the code.
I no longer use it, though; ***all of my code formatting is now handled by an extension called Prettier!*** 
I really value well-organized code that’s easy to navigate. 
In fact, I removed the "code map" feature in recent updates precisely because it had been generated by AI—even though I had modified it myself, I decided to just scrap it entirely.

But ... I think that's everything, my dear readers!

Thank you so much for checking out the project and following its development!
